# Files Validator

## Задание
На вход программе подается путь, в котором могут содержаться как файлы, так и папки с файлами. Необходимо пройтись по каждому файлу, в том числе и в подпапках, с определенным расширением (например `*.log`), и выявить и обработать в них определенные паттерны запрещенных строк:
1. Если встречаются строки вида `password=%строка_с_паролем%`, либо `password:%строка_с_паролем%` (между разделителем могут быть пробелы), то необходимо заменить `%строка_с_паролем%` на маску `***PASSWORD***`
2. Если встречаются строки вида `*****-*****-*****-*****`, где `*` - цифра, либо буква в верхнем регистре, то необходимо заменить всю строку на маску `***LICENCE KEY***`
3. Если встречаются строки, которые входят в список запрещенных слов (cм. таблицу), то необходимо заменить слово на соответствующее легальное слово:
  
    | запрещенное слово | замена         |
    | ----------------- | -------------- |
    | master            | primary        |
    | slave             | secondary      |
    | whitelist         | allowlist      |
    | blacklist         | denylist       |
    | manhours          | personhours    |
    | grandfathered     | legacy         |
    | dummy             | stub           |
    | sanitycheck       | integritycheck |
    | masterpassword    | mainpassword   |

## Запуск программы

1. Убедитесь, что у вас установлен .NET 9 SDK
2. Перейдите в директорию src и введите команду передав в качестве параметра путь до директории, в которой необходимо произвести манипуляции
```shell
dotnet run /Path/To/Directory
```
